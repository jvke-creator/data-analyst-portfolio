Data Visualization

This section presents visualizations created from the European Happiness dataset to explore patterns and relationships between happiness, socioeconomic factors, and regional differences.

Visualizations

The visualizations were created to highlight:

- Happiness scores across European regions
- The relationship between happiness and socioeconomic factors
- Differences in happiness levels across regions
- Key patterns and trends identified during the analysis

Tools Used

- Microsoft Excel
- Python (Pandas and Matplotlib)

The visualizations help communicate the findings from the data analysis in a clear and easy-to-understand format.
